# 🌍 Streamify

**Streamify** est une plateforme sociale d'apprentissage des langues qui permet aux utilisateurs du monde entier de trouver des partenaires linguistiques, discuter, créer des relations et participer à des appels vidéo.

L'application combine **authentification Google avec Clerk, profils utilisateurs, recommandations, système d'amis, chat en temps réel et visioconférence** dans une architecture moderne basée sur React, Node.js, Express et MongoDB.

### ✨ Fonctionnalités

* 🔐 Authentification Google avec Clerk
* 👤 Profils utilisateurs
* 🌍 Partenaires linguistiques
* 🤝 Demandes d'amitié
* 💬 Chat en temps réel
* 📹 Appels vidéo
* 🔔 Notifications
* 🎓 Onboarding linguistique
* 🗄️ Persistance des données avec MongoDB
* ⚡ API REST avec Express

### 🛠️ Stack

**Frontend:** React, Vite, React Router, TanStack Query, TailwindCSS, Zustand

**Backend:** Node.js, Express, MongoDB, Mongoose

**Authentication:** Clerk

**Real-time communication:** Stream

### 🎯 Objectif

Créer une plateforme permettant à chacun de **pratiquer une langue avec de vraies personnes**, de découvrir de nouvelles cultures et de développer ses compétences en communication grâce aux technologies modernes.
